# BOOK FLEX | 북플렉스 — 제품 요구사항 정의서(PRD)

- 버전: v1.3 (2026-11-07 BOOK FLEX 브랜드·플렉스칩·독서 XP·내부 기능명 통일)
- 작성일: 2026-11-07
- 대상: 중·고등학교 학급 독서 커뮤니티 웹앱
- 단계: 해커톤 본선 MVP 기획
- 상태: 사용자 확정사항 반영, 보상 수치와 기술 선택은 구현 제안으로 구분함

## 1. 프로젝트 개요

### 1.1 비전
1년 동안 책을 읽고 기록하고 자랑하는 문화를 학급에 확산한다. 학생이 매일 방문하고 싶은 자기만의 독서 공간을 만들고, 개인의 독서가 학급 전체의 독서 문화로 이어지도록 한다.

### 1.2 해결할 문제
- 독서 기록이 과제 제출이나 일회성 행사로 끝나기 쉽다.
- 학생들이 서로 어떤 책을 읽는지 자연스럽게 알기 어렵다.
- 읽은 분량과 꾸준함이 눈에 보이지 않아 독서의 성취감을 지속하기 어렵다.
- 교사가 학급 전체의 독서 현황을 한눈에 파악하기 어렵다.

### 1.3 핵심 가치
- **나:** 나만의 미니홈피형 서재, 오늘의 한 구절, 독서 이력과 꾸미기
- **지금:** 매일 읽은 페이지를 기록하고 독서 취향에 맞는 인문·고전 추천
- **함께:** 학급의 책장과 독서 기록을 공유하며 서로의 독서를 발견

### 1.4 범위
- **본선 MVP:** 한 학급(예: 20~30명)을 대상으로 동작하는 웹앱
- **장기 확장:** 여러 학급 및 학교 단위 공유, 학년·학교별 서재
- **서비스 지향:** 1년 동안 누적되는 기록을 보존하는 구조

## 2. 사용자와 권한

| 역할 | 주요 활동 | 접근 권한 |
|---|---|---|
| 학생 | 개인 공간 방문, 독서 기록, 책 추천, 서재 꾸미기, 학급 현황 보기 | 본인 기록 수정, 공개된 학급 정보 조회 |
| 교사 | 학생 등록·관리, 학급 기록 확인, 이상 기록 점검, 학급 운영 | 소속 학급 관리 |

**로그인 요구사항:** 학생은 교사가 등록한 학번·이름을 확인한 후 최초 접속 시 본인이 닉네임과 PIN(권장 6자리 이상)을 설정한다. 최초 설정을 타인이 선점하지 못하도록 교사가 제공한 일회성 학급 초대 코드 또는 학생별 최초 등록 코드를 추가한다. 이후 학번+PIN으로 접속하며 이름은 최초 본인 확인에 사용한다. PIN은 해시 저장하고 로그인 시도 횟수를 제한한다. 해커톤 시연에는 가상 학생만 사용한다.

## 3. 정보 구조(IA)

1. **MY FLEX — 개인 미니서재(개인 대시보드)** — 로그인 후 첫 화면
2. **FLEX CLASS — 우리 반 서재(학급 전체 탭)** — 학급 독서량·책장·학생별 공개 카드
3. **PAGE LOG — 독서 기록** — 책 선택, 읽은 페이지, 오늘의 한 구절
4. **BOOK PICK — 책 추천** — 개인 공간 한쪽의 작은 버튼으로 진입하는 3문항 밸런스 게임
5. **FLEX SHOP / FLEX LEVEL — 아이템 상점 / 칭호** — 플렉스칩 사용, 꾸미기, 해금 현황
6. **FLEX ADMIN — 교사용 대시보드** — 학급 기록과 운영 관리

※ 회의에서 언급한 '학급 탭'과 '학급 전체 탭'은 명칭이 중복될 수 있어 MVP에서는 개인 대시보드와 우리 반 서재로 구분한다. 다학급 확장 시 학급별 탭을 추가한다.

## 4. 주요 사용자 흐름

### 4.1 학생의 첫 방문
1. 학번·이름(+ 초기 코드/PIN)으로 접속한다.
2. 싸이월드 미니홈피를 연상시키는 개인 독서 공간이 첫 화면에 표시된다.
3. 별명·프로필·기본 서재 테마를 선택한다(간단한 기본값 제공).
4. 읽는 책을 등록하거나 화면 구석의 '나에게 맞는 책 찾기' 버튼을 누른다.

### 4.2 매일 독서 기록
1. 개인 서재에서 현재 읽는 책을 선택한다.
2. 날짜(기본값 오늘), 시작 페이지, 끝 페이지를 입력한다. 하루 단위 기록을 저장하며 같은 책의 마지막 도달 페이지와 누적 실제 읽은 페이지를 별도로 표시한다.
3. 오늘의 한 구절을 직접 입력한다. 한 구절은 학급 내부에 공개되며 책 제목과 작성자 닉네임을 함께 표시한다.
4. 저장 시 누적 독서량과 플렉스칩이 업데이트된다.
5. 완독 신청 시 1,000자 이하 감상문을 제출한다. 교사가 승인하면 완독으로 인정되어 개인 서재에 책등/책 표지가 한 권 추가된다.
6. 학급 서재와 학급 게시판에도 학생별 독서량(누적 읽은 페이지·완독 권수)이 갱신된다.

### 4.3 도서 추천(보조 기능)
1. 개인 대시보드의 작은 '책 추천' 버튼을 누른다.
2. 3개의 밸런스 게임형 질문에 답한다.
3. 중·고등학교 수준의 인문·고전 추천 도서 중 1~3권을 제안한다.
4. 추천 이유와 난이도/주제를 간단히 보여주고 '내 서재에 담기'를 제공한다.
5. 추천 결과는 첫 화면을 점유하지 않으며 필요할 때 다시 열람한다.

**밸런스 질문 예시(초안):**
- 세상을 바꾸는 이야기가 좋다 / 나 자신을 돌아보는 이야기가 좋다
- 현실의 고민이 좋다 / 상상 속 세계가 좋다
- 짧고 생각할 거리가 많은 글이 좋다 / 긴 서사에 몰입하고 싶다

※ 추천 도서의 실제 목록·저자·난이도·설명은 교사가 검토한 정적 데이터로 시작한다. AI 추천은 추후 확장 옵션이다.

## 5. 화면별 기능 요구사항

### 5.1 MY FLEX — 개인 대시보드·나의 미니서재
**필수**
- 싸이월드 미니홈피 감성의 개인 공간(프로필, 별명, 서재 영역)
- 현재 읽는 책과 오늘의 기록 버튼
- 오늘의 한 구절 카드(학급 공개)
- 개인 게시판 및 친구 댓글 알림
- 오늘의 개인 미션과 오늘의 우리 반 미션
- 누적 읽은 페이지, 읽은 책 수, 현재 플렉스칩, 보유 칭호 표시
- 완독한 책이 책장에 하나씩 쌓이는 시각적 표현
- 작게 배치된 '책 추천' 진입 버튼
- 보유 아이템으로 공간 꾸미기(초기에는 테마/소품 몇 개)

**제안**
- 방문자 수 대신 '이번 주 독서 방문일' 표시(독서 습관에 초점)
- 친구에게 보여줄 수 있는 공개 서재 카드

### 5.2 FLEX CLASS — 우리 반 서재·학급 전체 대시보드
**필수**
- 학급 전체 누적 독서 페이지 수
- 학급 전체 완독 권수
- 학생별 읽은 페이지 수와 공개 서재 진입
- 학급의 책들이 모여 커지는 공동 서재 시각화
- 최근 등록된 '오늘의 한 구절' 카드(학급 내부 공개)

**제안**
- 이번 주 함께 읽은 페이지 수, 공동 목표 달성 게이지
- 페이지 수 순위만 강조하지 않고 참여일·꾸준함도 함께 표시
- 친구 서재에 짧은 응원 스티커 남기기(운영 안정화 후)

### 5.3 FLEX ADMIN — 교사용 대시보드
**필수**
- 학급별 학생 명단 및 등록 현황
- 학생별 누적 페이지, 최근 기록일, 완독 권수
- 학급 전체 일별·주별 기록 현황
- 완독 감상문(1,000자 이하) 승인·반려 및 기록 수정 관리
- 부적절한 공개 문구·댓글 숨김/삭제
- 학생별 기록 열람, 플렉스칩 변경 이력 확인
- **학생별·학급 전체 독서 기록 다운로드**: Excel(.xlsx, 다중 시트) 및 CSV(시트별 개별 파일 또는 ZIP) 내보내기
- **완독 승인 시 학생이 선택한 독서 분야 및 감상문 확인**; 교사가 분야 수정·보완 의견 기록 가능
- **생활기록부 작성 참고용 학생별 독서 활동 요약**: 사실 기반 활동 내역과 날짜·출처를 모아 확인하고 다운로드

**제안**
- 칭호·플렉스칩 규칙 설정
- 학급 공동 목표 설정

### 5.4 BOOK PICK — 책 추천 화면
- 3개 밸런스 질문(각 2개 선택지)
- 사전 검토된 인문·고전 도서 데이터에 따라 추천
- 책 소개, 추천 이유, 예상 난이도/분량
- 내 서재에 담기

### 5.5 FLEX SHOP / FLEX LEVEL — 플렉스칩·칭호·상점
- 독서 기록, 개인 미션, 학급 공동 미션, 친구 서재 방문, 친구 한줄평 댓글에 대해 규칙 기반 플렉스칩 지급
- 독서 관련 누적 조건을 달성하면 칭호 잠금 해제
- 플렉스칩으로 개인 서재의 바닥·벽지·가구·조명·장식 등 단계별 아이템 구매
- 구매한 아이템을 개인 화면에 적용
- 플렉스칩 및 구매 내역 저장

**보상·상점·칭호의 상세 초기 제안은 11B절 참조.** 실제 개발 시 플렉스칩 지급은 서버에서 검증하며, 동일 이벤트에 대한 중복 지급을 금지한다.

| StudentBook | student_book_id, student_id, book_id, status, started_at, finished_at |

| TitleAchievement | student_id, title_id, unlocked_at, equipped |

| Purchase | student_id, item_id, purchased_at |

학번은 학급 내에서만 고유하게 취급하고, 내부 데이터 연결에는 별도 student_id를 사용한다. 학급·학교 간 확장 가능성을 위해 class_id를 모든 기록과 연결한다.

### 6A. BOOK FLEX 브랜드 적용 데이터 규칙
- `chip_balance`, `chip_transactions` (type, amount, source_event_id, created_at): 플렉스칩 잔액 및 지급·사용·회수 원장. 동일 `source_event_id` 중복 지급 불가.
- `reading_xp_total`, `reading_xp_transactions` (type, amount, source_event_id, created_at): 독서 XP 누적·정정 이력. 구매 시 차감하지 않음.
- `reading_level`: 독서 XP 누적에 따른 파생값. `titles`/`unlocked_titles`는 누적 독서 성취 기준으로 해금.
- `shop_items` (item_id, slot_type, chip_price, unlock_rule), `inventory` (student_id, item_id), `room_layouts` (student_id, equipped_items): FLEX SHOP 구매 및 MY FLEX 공간 꾸미기.
- `mission_rewards`, `visit_rewards`, `comment_rewards`: FLEX MISSION/FLEX VISIT/FLEX FEED 보상 이벤트를 서버에서 중복 방지.
- API와 화면 모두 통화 단위를 **플렉스칩**으로 통일하고, 독서 XP는 별도 숫자로 표시한다. 기존 `points` 필드가 있다면 신규 스키마로 마이그레이션한다.

## 7. 비기능 요구사항

- **반응형:** 학생 휴대전화와 교사 PC 모두에서 이용 가능
- **데이터 영속성:** 새로고침·다른 기기에서도 기록 유지(공용 DB 필요)
- **권한 분리:** 학생은 본인 기록만 수정, 교사는 소속 학급 관리
- **개인정보 최소화:** 실명 공개 범위는 학급 내부로 제한하고 공개 화면은 별명 사용 가능
- **보안:** 학생 식별번호+이름만으로 접근을 허용하지 않음; 비밀정보는 서버에서 검증
- **콘텐츠 관리:** 한 구절 및 공개 메시지 신고/숨김 또는 교사 관리 기능
- **저작권:** 책 표지·본문 이미지의 사용 권리 확인; 학생이 직접 입력한 짧은 인용은 출처 표시
- **접근성:** 색상 외에도 텍스트로 상태 표시, 키보드 사용 고려

## 8. 본선 MVP 개발 우선순위

### P0 — 반드시 작동
1. 한 학급 가상 학생 3~5명으로 로그인/계정 전환 데모
2. 개인 미니서재 및 책장 표시
3. 책 선택, 일일 읽은 페이지·한 구절 저장
4. 누적 페이지·완독 권수 자동 집계
5. 학급 전체 서재 대시보드
6. 교사용 대시보드(학생별 독서 이력 조회, 완독 승인, 기본 CSV 다운로드)
7. 기본 플렉스칩 지급 및 칭호 2~3개 해금

### P1 — 시간이 허용되면
1. 3문항 밸런스 게임 도서 추천
2. 상점에서 아이템 3~5개 구매 및 꾸미기
3. 친구 서재 방문과 공개 한 구절 확인

### P2 — 후속 개발
1. 실시간 응원/댓글 및 알림
2. 여러 학급·학교 단위 공유
3. AI 기반 도서 추천 및 독서 성찰 질문
4. 연간 독서 리포트 고도화(기본 CSV 다운로드는 P0에 포함)

> 사용자가 요청한 기능은 모두 제품 범위에 포함하되, 해커톤 시간 제약을 고려해 P0/P1/P2로 구현 순서를 구분한다.

## 9. 수용 기준(Acceptance Criteria)

- 학생이 접속하면 자신의 미니서재가 첫 화면에 나타난다.
- 학생이 오늘 읽은 페이지를 저장하면 누적 페이지와 학급 합계가 갱신된다.
- 같은 기록을 새로고침하거나 중복 제출해도 플렉스칩이 중복 지급되지 않는다.
- 책을 완독하면 개인 책장에 책이 한 권 추가된다.
- 오늘의 한 구절을 저장하면 개인 카드에 나타나고, 공개로 설정한 경우 학급에도 나타난다.
- 학급 화면에서 학생별 독서 현황과 학급 전체 독서 현황을 확인할 수 있다.
- 교사는 학생별 기록과 학급 집계를 조회할 수 있다.
- 교사는 학급/학생/기간을 지정하여 완독 도서, 분야, 감상문, 한줄평, 독서 기록, 미션 수행 내역을 CSV로 다운로드할 수 있다.
- 완독 신청 시 학생이 독서 분야를 선택해야 하며, 교사는 분야와 감상문을 함께 확인하여 승인한다.
- 추천 기능을 구현한 경우, 3문항 답변 후 사전 등록된 책이 추천된다.
- 상점을 구현한 경우, 잔액 부족 시 구매가 차단되고 구매 후 아이템이 적용된다.

## 10. 해커톤 시연 시나리오(약 3분)

1. **0:00~0:30:** 학번·이름(데모 계정)으로 접속 → 나만의 싸이월드형 미니서재 소개
2. **0:30~1:10:** 읽는 책 선택 → 오늘 12페이지 읽기 및 한 구절 기록 → 플렉스칩 획득
3. **1:10~1:40:** 완독 처리 → 개인 책장에 책 추가 → 칭호 해금
4. **1:40~2:15:** 우리 반 서재 이동 → 학급 전체 독서량과 친구의 서재 확인
5. **2:15~2:45:** 교사용 대시보드에서 학생별·학급별 독서 현황 확인
6. **2:45~3:00:** 1년 누적 독서 문화 및 학급·학교 확장 비전 제시

## 11. 회의 확정 사항 및 남은 선택

### 11.1 확정 사항
- 학생은 최초 접속 시 **개인 닉네임과 PIN을 직접 설정**한다(최초 등록 선점 방지용 교사 초대 코드 필요).
- 독서 기록은 **날짜별·책별 시작 페이지와 끝 페이지**로 입력하며 **누적 읽은 페이지와 현재 도달 페이지**를 별도 표시한다.
- **오늘의 한 구절은 학급 내부 공개**한다.
- 책은 **사전 추천 목록에서 선택하거나 학생이 직접 등록**할 수 있다.
- **완독은 1,000자 이하 감상문 제출 → 교사 승인** 후 인정한다.
- **친구 서재 방문, 친구 한줄평에 댓글, 개인 미션, 우리 반 공동 미션**을 보상에 포함한다.
- **개인 화면·학급 탭·학급 게시판**에 개인별 독서량을 표시한다(학급 구성원만 열람).
- 개인 대시보드에 **나의 서재 + 개인 게시판 + 매일 미션**을 배치한다.
- 프런트엔드와 관리형 데이터베이스를 결합한 웹앱으로 구현한다.

## 11A. 상세 기능 규격 — 독서 기록·완독·공개

### 페이지 기록 규칙
- 필드: `reading_date`, `student_book_id`, `start_page`, `end_page`, `pages_read`, `last_reached_page`.
- 시작/끝은 **양끝 포함**으로 계산한다. 예: 11~20쪽 → 10쪽. 동일 책·동일 날짜 여러 구간 입력 가능하나 중복 구간은 누적하지 않는다.
- 누적 읽은 페이지 = 승인된/유효한 읽기 구간의 **중복 제거 합계**. 같은 구간을 다시 기록해 플렉스칩을 얻지 못한다.
- 현재 도달 페이지 = 해당 책의 기록 중 가장 높은 끝 페이지(단, 중간 페이지를 건너뛰었다고 그 구간을 읽은 것으로 추정하지 않음).
- 기록 날짜를 바꿀 수 있으나 미래 날짜 입력 불가; 과거 기록 허용 범위는 교사가 설정(초기 제안 7일).
- 직접 등록 도서에는 제목·저자·출판사/판본·총페이지를 입력한다. 판본마다 쪽수가 다르므로 총페이지는 학생이 소유한 판본 기준.
- **독서량 표시**: 개인 홈 상단/내 게시판 상단/우리 반 서재 학생 카드/학급 게시판 학생 작성자 옆에 `누적 N쪽 · 완독 M권` 표시. 순위보다 누적 성장과 참여일을 강조한다.

### 완독 승인
1. 학생이 책 상세에서 `완독 신청`을 누르고 **독서 분야 1개를 필수 선택**한 뒤 1~1,000자 감상문을 제출한다. 분야는 `문학`, `인문·철학`, `역사`, `사회`, `과학·기술`, `예술`, `기타`를 기본 제안으로 제공하며 교사가 학급 운영에 맞게 수정할 수 있다. 이는 앱의 독서 활동 분류이며 학교생활기록부의 공식 분류 체계를 의미하지 않는다.
2. 상태는 `대기`로 표시; 완독 권수 및 완독 보상에는 미반영.
3. 교사가 선택 분야·감상문·독서 이력을 확인한 후 `승인` 또는 `반려(사유)` 처리. 필요한 경우 분야를 수정하고 수정 이력을 남긴다.
4. 승인 시 1회만 완독 보상·책장 적재·칭호 조건 갱신. 반려 시 수정 후 재신청 가능.
5. 감상문은 기본 비공개(학생 본인과 교사만 열람); 학급 공개는 별도 선택 기능으로 추후 확장.

### 게시판·한 구절·댓글
- 학생 개인 게시판: 독서 한줄평·한 구절·독서 근황 카드; 친구들이 방문하여 댓글 작성.
- 학급 게시판: 학급 구성원들의 최신 한 구절/한줄평 피드, 작성자 닉네임과 누적 독서량 표시.
- 한 구절은 학급 공개를 기본으로 하며 출처(책 제목·저자)를 함께 표시; 과도한 장문 전재를 제한한다.
- 댓글: 학급 내 인증 학생만 작성·열람, 교사는 숨김·삭제 가능, 작성자는 자기 댓글 삭제 가능.

## 11B. 플렉스칩·독서 XP 경제·칭호·상점 (수치는 MVP 초기 제안)

### 이중 보상 체계 (필수)
- **플렉스칩(FLEX CHIP)**: 소비 가능한 게임 화폐. 유효한 독서 기록·미션·친구 서재 방문·댓글·완독 승인 등으로 획득하고 FLEX SHOP에서 소비한다. 잔액은 `earned - spent + adjustments`로 계산한다. 음수 잔액 금지.
- **독서 XP(READING XP)**: 소비하지 않는 누적 성장 경험치. 실제 독서·기록·완독·독서 성찰 중심으로 부여하며 레벨과 칭호 해금에 사용한다. 친구 방문이나 댓글만으로 독서 레벨이 과도하게 상승하지 않도록 독서 XP는 원칙적으로 독서 관련 검증 활동에만 지급한다.
- **중요:** 플렉스칩을 사용해도 독서 XP, 레벨, 칭호, 독서 기록은 감소하지 않는다. 플렉스칩 지급/회수와 XP 지급/정정은 각각 별도 원장에 기록한다.
- **UI 예시:** `Lv.5 문장 수집가 | 350 XP | 120 플렉스칩` (수치는 예시).
- **MVP 독서 XP 제안:** 첫 유효 독서 기록 +10 XP/일, 중복 제외 읽은 페이지 5쪽당 +2 XP(일일 최대 +20), 한 구절 기록 +5 XP/일, 교사 완독 승인 +40 XP/권. XP는 위·변조 및 중복 입력을 서버에서 검증한다.
- **레벨 구간 예시:** Lv.1 0 XP, Lv.2 50 XP, Lv.3 150 XP, Lv.4 300 XP, Lv.5 500 XP. 실제 운영 전 학급 독서량에 맞게 조정한다.

### 플렉스칩 획득
| 활동 | 초기 제안 | 제한 및 악용 방지 |
|---|---:|---|
| 하루 첫 유효 독서 기록 | +10칩 | 하루 1회 |
| 실제 읽은 페이지 | 5쪽당 +2칩 | 하루 최대 +20칩, 중복 구간 제외 |
| 오늘의 한 구절 등록 | +5칩 | 하루 1회, 출처 필수 |
| 개인 미션 완료 | +15칩 | 하루 1회, 검증 조건 충족 |
| 우리 반 공동 미션 전원 달성 | **모든 학생 +30칩** | 학급 전원 완료 시 하루 1회, 서버 일괄 지급 |
| 친구 서재 방문 | 첫 방문 +3칩, 하루 서로 다른 친구 3명까지 | 같은 친구 반복 방문 플렉스칩 없음, 하루 최대 +9칩 |
| 방문 다양성 보너스 | 서로 다른 친구 5명 누적 방문 시 +10칩 | 주 1회, 실제 고유 친구 수 기준 |
| 친구 한줄평에 댓글 | +5칩 | 하루 서로 다른 글 2개까지, 최소 10자, 자기 글 제외 |
| 교사 완독 승인 | +40칩 | 책별 1회, 승인 시 지급 |

**설계 원칙:** 방문 횟수가 많을수록 누적 보상이 증가하되, 새로고침·반복 클릭으로 플렉스칩을 무한 획득할 수 없게 **고유 친구 방문**을 기준으로 한다. 댓글 삭제/교사 삭제 등 악용 사례에는 보상 회수 가능. 모든 지급은 서버 트랜잭션과 고유 이벤트 키로 멱등 처리.

### 아이템 상점: 작은 소품 → 구조·인테리어 → 프리미엄 공간
| 단계 | 구매 가능 아이템 예시 | 초기 가격대 | 해금 조건(제안) |

| 2 책상 주변 | 독서등, 쿠션, 책더미, 포스터, 작은 러그 | 70~130칩 | 누적 100쪽 또는 기록 3일 |
| 3 벽·바닥 | 벽지(크림·벽돌·우드), 바닥재(원목·타일·카펫), 창문 프레임 | 150~250칩 | 누적 250쪽 또는 완독 1권 |
| 4 가구 | 책상, 의자, 낮은 책장, 소파, 대형 러그 | 260~450칩 | 누적 500쪽 또는 완독 2권 |
| 5 공간 연출 | 큰 책장, 벽난로, 통창, 조명 세트, 식물 코너 | 500~800칩 | 누적 1,000쪽 또는 완독 3권 |
| 6 특별 테마 | 별빛 서재, 비밀 도서관, 숲속 서재, 레트로 미니홈피 | 900~1,500칩 | 장기 활동/교사 승인 완독 5권 |

- 구매는 **현재 플렉스칩 잔액**에서 차감, 해금은 **누적 성취(독서량·완독·기록일)**로 판정하여 플렉스칩을 써도 칭호/해금이 사라지지 않음.
- 기본 벽·바닥·책장은 무료 제공. 장식 아이템은 실제 서재 화면에서 배치/적용/해제 가능.
- MVP는 1~3단계 아이템 중 6~10종을 우선 구현하고, 나머지는 잠금 미리보기로 노출.

## 11C. 매일 미션

### 미션 노출
- 개인 대시보드 상단에 `오늘의 개인 미션`과 `오늘의 우리 반 미션` 카드 동시 노출.
- 한국시간 날짜를 기준으로 매일 서버가 미션 풀에서 1개씩 결정(하루 동안 모든 학생에게 동일한 학급 미션; 개인 미션은 학생별 무작위/순환).
- 새로고침으로 미션이 바뀌지 않으며, 완료 여부는 서버에 저장.

### 미션 풀 예시
| 종류 | 예시 | 자동 검증 방법 |
|---|---|---|
| 개인 | 오늘 10쪽 이상 읽고 기록하기 | 당일 중복 제외 페이지 합계 ≥10 |
| 개인 | 오늘의 한 구절 남기기 | 당일 한 구절 저장 |
| 개인 | 친구 2명의 서재 방문하기 | 당일 고유 방문 대상 ≥2 |
| 개인 | 친구의 한줄평에 댓글 1개 달기 | 당일 유효 댓글 ≥1 |
| 학급 | 오늘 모든 학생이 1쪽 이상 읽기 | 활성 학급 학생 전원 유효 기록 |
| 학급 | 오늘 모든 학생이 한 구절 남기기 | 활성 학급 학생 전원 한 구절 |
| 학급 | 오늘 모든 학생이 친구 서재 1곳 방문 | 활성 학급 학생 전원 고유 방문 ≥1 |

- **전원 달성 보너스:** 학급 활성 학생 전원이 같은 날짜의 공동 미션을 완료하면 **전원 +30칩**를 1회 지급하고 학급 대시보드에 축하 배너 표시.
- 교사는 장기 결석 등으로 참여가 어려운 학생을 해당 날짜의 공동 미션 대상에서 제외할 수 있음(변경 이력 기록). 학급 공동 미션은 개인별 비교가 아닌 협력 성취로 설계.
- MVP는 미션 2~3종씩 구현하고 매일 고정된 시드로 랜덤 배정해 서버 스케줄러 없이도 동작 가능.

## 11D. 기술 구성 및 데이터 추가

### 권장 아키텍처 (구현 제안)

- **배포:** Vercel + 환경변수로 DB 키 관리. 관리자 서비스 키는 브라우저에 노출하지 않음.

- **연간 운영:** `academic_year`, `class_id` 분리; 다음 해 새 학급 개설과 기록 아카이빙 지원.

## 11F. 갱신된 본선 구현 순서와 수용 기준

**P0 (시연 필수)**: 학생 최초 닉네임/PIN 설정(데모 안전 처리) → 개인 미니서재/게시판 → 날짜별 시작·끝 페이지 기록 및 누적 → 학급 공개 한 구절/독서량 → 친구 서재 방문·댓글 → 개인/학급 미션 진행률 → 교사용 완독 승인 → 기본 플렉스칩 원장.

**P1 (본선에서 가능하면)**: 3문항 추천, 상점 아이템 6~10종 구매·배치, 칭호 잠금 해제, 학급 전원 미션 보너스 자동 지급.

**P2 (후속)**: 고급 테마 전체, 여러 학급/학교 공유, 알림·연간 리포트, 고급 부정행위 탐지.

**추가 수용 기준**
1. 새 학생은 최초 등록 코드를 통과한 후 닉네임·PIN을 스스로 설정할 수 있다.
2. 같은 날짜·책의 페이지 중복 구간을 재등록해도 누적 독서량/플렉스칩이 중복 증가하지 않는다.
3. 학생이 1,000자를 초과하는 완독 감상문을 제출하면 저장되지 않는다.
4. 교사 승인 전에는 완독 권수·완독 보상·책장 적재가 발생하지 않는다.
5. 친구 서재 방문은 고유 친구 수 기준으로 플렉스칩이 지급되며 새로고침 반복으로 플렉스칩을 벌 수 없다.
6. 친구 한줄평에 유효 댓글을 달면 한도 내에서 플렉스칩을 받으며, 자기 글 댓글은 보상하지 않는다.
7. 개인 미션 완료와 학급 전원 미션 완료 시 보상은 각각 한 번만 지급된다.
8. 개인 홈·학급 탭·학급 게시판에 표시되는 누적 페이지/완독 권수는 같은 데이터에서 계산된다.
9. 교사는 완독 신청을 승인·반려할 수 있고, 댓글을 숨김 처리할 수 있다.

## 13. v1.2 추가 확정 — 교사용 기록 다운로드 및 생활기록부 참고 자료

### 13.1 목적과 원칙
- 교사가 **한 학생의 연간 독서 활동 전체**와 **학급 전체의 독서 활동**을 한 번에 내려받아 지도·상담·학교생활기록부 작성의 **근거 자료**로 활용할 수 있도록 한다.
- 학생의 실제 입력과 교사 승인 이력을 원자료로 제공한다. AI가 학교생활기록부 문구를 자동으로 확정하거나 학생의 성향·역량을 근거 없이 추론하지 않는다.
- 학생 공개 게시물과 교사 전용 기록을 구분한다. **완독 감상문 원문과 미션 세부 이력은 교사·본인만 열람**하며 학급 공개 화면에 자동 노출하지 않는다.
- 학교생활기록부 기재 가능 여부와 실제 문구는 해당 학년도 학교생활기록부 기재요령·학교 지침에 따라 교사가 최종 판단한다. 앱의 `독서 분야`는 운영 편의상 분류이며 공식 생활기록부 입력 항목이라고 주장하지 않는다.

### 13.2 완독 인증 화면 추가 입력
1. 책 선택 → `완독 인증` → **독서 분야 선택(필수, 단일 선택)** → **1,000자 이하 감상문(필수)** → 제출.
2. 분야 기본값: 문학 / 인문·철학 / 역사 / 사회 / 과학·기술 / 예술 / 기타. 교사는 분야 목록을 편집할 수 있다.
3. 감상문 입력란 아래 `이 책을 통해 새롭게 알게 된 점 또는 생각이 달라진 점` 안내 문구를 제시하되, 정형화된 답변을 강제하지 않는다.
4. 신청 상태: 임시저장(선택), 승인 대기, 승인, 반려. 승인 전까지 완독 권수·완독 보상 미반영.
5. 교사용 승인 카드: 학생/학번, 도서명·저자·판본, 독서 기간, 페이지 이력, 선택 분야, 감상문 원문, 제출일, 승인/반려 버튼, 교사 메모.
6. 승인 시 분야·승인자·승인 시각을 저장하고, 수정 시 변경 이력을 남긴다.

### 13.3 FLEX ADMIN — 교사용 대시보드 — `기록 다운로드` 메뉴 (필수)
**필터:** 학급(현재는 1개), 학생(전체 또는 개별), 기간(시작일~종료일/학년도 전체), 기록 유형, 승인 상태.

**다운로드 형식**
- **Excel `.xlsx` 1개 파일**: 아래 7개 시트를 포함하는 통합 내보내기(권장 최종 구현).
- **CSV**: 시트별 UTF-8 BOM CSV 다운로드 또는 여러 CSV를 ZIP으로 묶어 다운로드. Excel에서 한글 깨짐을 방지한다.
- 파일명 예: `BOOK_FLEX_2학년2반_독서기록_2026-03-01_2026-12-31.xlsx` (예시 데이터이며 실제 학급명·기간으로 생성).

| 시트 | 핵심 열(예시) | 활용 |
|---|---|---|
| 01_학생요약 | 학번, 학생명, 닉네임, 누적 읽은 쪽수, 독서 참여일, 승인 완독 권수, 마지막 활동일, 미션 완료 수 | 학급 현황·학생별 활동 확인 |
| 02_완독도서 | 학번, 학생명, 도서명, 저자, 분야, 시작일, 완독 신청일, 승인일, 승인 상태, 교사 메모 | 승인 완독 도서·분야 확인 |
| 03_완독감상문 | 학번, 학생명, 도서명, 분야, 감상문 원문, 글자 수, 제출일, 승인 상태 | 독서 후 생각의 변화 등 원문 확인 |
| 04_일일독서기록 | 학번, 학생명, 기록일, 도서명, 시작 쪽, 끝 쪽, 실제 읽은 쪽수, 해당 책 도달 쪽, 입력 시각 | 날짜별 활동 근거 |
| 05_한줄평과한구절 | 학번, 학생명, 작성일, 도서명, 유형(한줄평/한 구절), 내용, 공개 범위 | 학생 작성 텍스트 확인 |
| 06_미션활동 | 학번, 학생명, 날짜, 개인/학급 미션, 미션명, 완료 여부, 완료 시각, 교사 확인 여부, 지급 플렉스칩 | 독서 관련 미션 수행 근거 |
| 07_독서참여활동 | 학번, 학생명, 활동일, 활동 유형(댓글/서재 방문 등), 관련 도서/게시글, 댓글 내용(해당 시), 플렉스칩 | 학급 내 독서 교류 활동 확인 |

**내보내기 정책**
- 모든 시트는 동일한 `student_id`, 학번, 학생명으로 연결 가능하도록 한다. 학번은 Excel에서 앞자리 0이 보존되도록 **텍스트 형식**으로 출력한다.
- 날짜는 `YYYY-MM-DD`, 일시는 학교 현지 시간대로 명확하게 출력한다. 긴 감상문은 줄바꿈을 유지한다.
- 기간 필터는 활동 발생일 기준을 기본으로 하되 완독 도서에는 신청일·승인일을 모두 제공한다.
- 원문 기록과 집계값을 구분한다. 삭제·수정된 기록의 감사 이력은 교사 권한에서 별도 확인 가능하도록 설계한다.
- 학생별 다운로드 시 해당 학생 기록만 포함한다. 교사 본인 학급에만 다운로드 권한을 부여하고 다운로드 실행 로그를 저장한다.
- 다운로드 파일에는 학생 개인정보가 포함되므로 **접근 권한 확인·외부 공유 주의 문구**를 제공하고, 서버에 불필요하게 영구 보관하지 않는다.
- CSV 수식 주입 방지: `=`, `+`, `-`, `@`로 시작하는 학생 입력값을 스프레드시트에서 실행되지 않도록 안전하게 이스케이프한다.

### 13.4 FLEX ADMIN — 생활기록부 작성 참고용 `학생별 독서 활동 요약`
- 교사용 학생 상세 화면에서 `독서 활동 요약 보기`를 제공한다.
- 표시 내용: 기간별 승인 완독 도서·저자·분야, 학생이 직접 작성한 한줄평/감상문, 개인·학급 미션 수행, 독서 참여일 및 누적 페이지.
- **교사가 사실 확인할 수 있도록** 각 요약 항목에서 원문 기록/날짜/승인 내역으로 이동 가능해야 한다.
- 요약은 **관찰·활동 근거 정리**에 한정하고, 생활기록부 기재 문장 자동 확정·자동 입력 기능은 제공하지 않는다.
- 선택적으로 `학생별 요약 CSV`를 내려받을 수 있다. 실제 기재 시 학교 기준에 따라 교사가 선별·검토한다.

### 13.6 구현 우선순위와 수용 기준
- **P0 (해커톤 필수):** 완독 신청 시 분야 선택 → 감상문 작성 → 교사 승인, 교사용 학급 전체/학생별 기록 **CSV 다운로드**, 최소 `학생요약·완독도서·완독감상문·일일독서기록·한줄평과한구절·미션활동`의 데이터를 내보낼 수 있어야 한다.
- **P1 (가능하면):** `.xlsx` 다중 시트 통합 파일, `독서참여활동` 시트, 필터 UI, 학생별 요약 화면.
- **P2 (확장):** 승인 변경 감사 이력 고도화, 학년도별 비교, 학교 공식 문서 서식에 맞춘 내보내기(학교 승인 필요).

**검증 시나리오:** 학생 A가 문학 분야를 선택해 완독 감상문을 제출한다 → 교사가 승인한다 → 학생 A의 완독 권수·책장이 갱신된다 → 교사가 A만 선택해 CSV를 다운로드한다 → 도서명·분야·감상문·승인일이 정확히 포함된다 → 학급 전체 내보내기 시 학생 B의 기록도 포함된다 → 학생 계정에서는 교사용 다운로드 기능에 접근할 수 없다.
