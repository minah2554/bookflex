# BOOK FLEX 미니서재 · FLEX SHOP 이미지 제작 요청서

북플렉스는 중·고등학생이 책을 읽고 기록하면 **칩**을 모아 **자기 방(미니서재)을 꾸미는** 독서 커뮤니티 웹앱입니다.
이 방 안에 들어갈 물건 이미지를 **2000년대 싸이월드 미니룸 스타일**로 제작해 주세요.

---

## 1. 스타일 가이드

- **시점**: 등각 투영(아이소메트릭) 고정. 가로:세로 = 2:1 비율의 마름모 바닥(약 26.6° 기울기). 모든 물건이 같은 각도로 보여야 한 방에 같이 놓았을 때 어긋나지 않습니다.
- **보는 방향**: 방의 뒤쪽 모서리가 위, 왼쪽 벽·오른쪽 벽·바닥이 보임. 물건은 앞쪽(정면 오른쪽 아래)을 향합니다.
- **분위기**: 싸이월드 미니룸처럼 아기자기하고 귀여운 픽셀 감성의 일러스트. 두꺼운 외곽선 없이 **얇은 진한 톤 외곽선(1px) + 부드러운 면 채색 + 간단한 그림자 한 단계**. 사실적 질감, 그라데이션 과다 사용은 피해 주세요.
- **색감**: 파스텔 톤 + 포인트 컬러(분홍 #e98ba0, 하늘 #9fd6f2, 연노랑 #ffe27a, 초록 #55b573, 주황 #f7a65a). 앱 배경(하늘색·연보라·주황 포인트)과 어울려야 합니다.
- **빛**: 왼쪽 위에서 비춤. 왼쪽 면은 밝게, 오른쪽 면은 조금 어둡게, 윗면이 가장 밝게.
- **그림자**: 물건 아래 바닥에 옅은 타원/마름모 그림자(투명도 15~20%)를 이미지에 포함해 주세요.
- **금지**: 실제 브랜드·캐릭터·저작권 있는 이미지, 글자(한글 포함)가 들어간 이미지(책 제목 등은 모양만).
- **독서 컨셉**이 드러나게: 책·책갈피·독서등·책장 등은 특히 정성을 들여 주세요.

---

## 2. 파일 규격 (중요)

두 종류를 납품해 주세요. **1x = 앱에서 보이는 크기**이고, **고해상도 화면 대응을 위해 2x로 납품**해 주세요.

### A. 방 안에 놓이는 이미지 (물건 1개당 1장)

| 항목 | 규격 |
|---|---|
| 캔버스 | **960 × 720 px (방 전체 크기 2x)**, 투명 배경 PNG-24 |
| 위치 | 물건이 **방 안의 정해진 자리에 이미 놓인 상태**로 그려서 캔버스에 배치 (물건마다 같은 캔버스에 겹치기만 하면 되게) |
| 이유 | 개발에서 좌표 계산 없이 같은 크기로 겹쳐 올리기만 하면 되고, 가림 순서(앞/뒤)만 정하면 됩니다 |

> 첨부 가이드: **방 템플릿 PSD/PNG를 먼저 전달**해 드립니다(마름모 바닥과 벽 격자, 각 물건의 자리 표시). 템플릿 위에 레이어로 그려 주세요. 템플릿이 필요하면 요청해 주세요.

방 좌표(2x 기준, 캔버스 960×720):

- 방 뒤쪽 꼭짓점: **(480, 300)**
- 바닥 마름모: 위 (480,300) · 오른쪽 (860,490) · 아래 (480,680) · 왼쪽 (100,490)
- 벽 높이: 꼭짓점에서 위로 **240 px** (왼쪽 벽·오른쪽 벽 모두)
- 왼쪽 벽은 위 꼭짓점→왼쪽 꼭짓점 방향, 오른쪽 벽은 위 꼭짓점→오른쪽 꼭짓점 방향

### B. 상점 카드 썸네일 (물건 1개당 1장)

| 항목 | 규격 |
|---|---|
| 크기 | **256 × 256 px**, 투명 배경 PNG |
| 구도 | 물건 하나를 가운데에 꽉 차게(여백 약 10%), 같은 시점·그림자 포함 |
| 용도 | FLEX SHOP 카드(화면에서는 약 96×96px로 표시), 구매 확인 영역 |

### 파일 이름

`room_<id>.png` (방 안용), `thumb_<id>.png` (썸네일). 아래 목록의 `id`를 그대로 사용해 주세요. 예: `room_lamp.png`, `thumb_lamp.png`.

## 4. 앞/뒤 가림 순서 (참고)

개발에서 이 순서로 겹쳐 올립니다. 물건 이미지는 **자기 아래 물건과 겹쳐도 어색하지 않게** 그려 주세요.

벽·바닥 → 벽걸이(창문·포스터·액자·노을 포스터) → 러그류 → 침대 → 책장·쿠션 → 화분·책더미·소파 → 책상 → (아바타) → 책상 위 소품(독서등·머그컵·시계·책갈피) → 의자

방 가운데 **러그 위에 학생 아바타**가 서 있으니, 러그와 가구는 아바타(약 24×50 px)가 가운데 서도 가려지지 않는 위치에 두세요.

## 5. 납품 방식

- 1차: **스타일 시안 3장**(침대 / 책장 / 독서등)을 먼저 전달해 확인 후 나머지 진행
- 폴더 구조: `room/` (방 안용 960×720), `thumb/` (256×256)
- 원본 편집 파일(PSD/CLIP 등)도 함께 전달
